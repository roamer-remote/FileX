# Docs

`docs/` stores project-level reference material that is not part of the
feature-spec or review workflow. Feature specifications, design system material,
and review output live under `specs/`.

| Need | Location |
| --- | --- |
| Software copyright application material | `docs/软著/` |
| Vendor API/reference material | `docs/第三方供应商/` |
| Product introduction decks and drafts | `docs/项目介绍/` |
| Feature requirements, plans, tasks, and per-feature reviews | `specs/<feature-id>/` |
| Review role, review templates, and legacy project-wide reviews | `specs/_reviews/` |
| Design guidance, references, prototypes, and design drafts | `specs/_design/` |

Keep project-level reference bundles in `docs/`. Keep feature workflow artifacts
in `specs/`.
