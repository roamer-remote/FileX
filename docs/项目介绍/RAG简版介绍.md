## 企业 AI 落地的进化之路

### 老板和领导
	
	老板和领导具有很多想法，苦于办事人员的效率和能力，不能及时推进和尝试

### 推进方向
- 首先推进个人能力的提升
- 不要一上来就推进整个部门或者企业

## 三重关系的效率

- 人跟人（最慢）
- 人和agent
- agent 和 agent

### 聪明的打法
	1. 提升每个人的技术能力和边界
	2. 减少人和人的低效率，无聊的接触和沟通

## 怎么做?
	Agent + skills + Data
	1. 一个智能体去合理的调用技能去处理数据。
		a. 一般的数据->看一眼抛弃
		b. 有用的数据变成新的数据
	2. 好的skill 保持，优化推进，变成新的 skill

## 误区
### 耗费太多的精力去找
	1. “好的” 大模型
	2. “好的” agent
	没有必要，找自己熟悉的，喜欢的就行。原因是：
	a. 迭代太快。
	b. 短期内就会同质化。
	c. 用流行的，成本合适的，顺手的。不要去折腾，用熟就行。
	d. DeepSeek ，GLM 等 国内的
	e. WorkBuddy , Hermes , OpenClaw ,codex ,claude code 等。
### agent 和 模型 是最简单的。
	1. 花钱就可以买到的
	2. 大家都差不多。	

## 真正的难点
### skills
公司的第二大数字资产
1. 怎么把重复性的流程 做成 skill
2. 把以前的流程进行优化
	a. 计算机开始的时候，作为打字机，输入文档后，打印，归档。流程使然
	b. 现在用了 agent ，生成的文档依然进入 OA，ERP，SAAS	

### data
公司的第一大数字资产
1. 文档
2. 会议纪要
3. 业务数据
4. 其他数据怎么获取？
	a.  买？
	b.  爬？
5. 有了数据怎么管理？让 AI 和 agent 更好的使用。
6. agent 和 模型，公开的，花钱就可以买到的。
7. skills 可以慢慢学，慢慢抄。
8. 正在拉开企业差距的，依然是信息差。
	1. 谁的数据好！
	2. 谁的数据管理的好！
	3. 谁的数据应用的好！
