钉技能 · 操作流向图

场景 A · 查资料库

「钉一下：发票报销要哪些材料？」

  1. 识别为查资料库未提到外网，走默认路径
  2. 语义搜索「报销」「发票」「材料」找到内规或制度文件相关段落
  3. 必要时读完整笔记表格、清单类问题会补读全文
  4. 回复并标注出处例：「根据《财务报销制度》第 3 页……」

场景 B · 外网入库

「帮我在 PubMed 找 CRISPR 最新论文，入库打标」

  1. 识别为外网 + 入库组合任务先 PubMed 检索（或您要求时先查库）
  2. 整理论文清单题名、作者、期刊、链接
  3. 下载并上传资料库确认存放文件夹
  4. 双路合成笔记 + 打标签如「CRISPR」「基因编辑」
  5. 校验完成后汇报告知文件编号与存放位置

场景 C · 链接入库

「把这个链接存进资料库：https://…」

  1. 识别为链接入库
  2. 打开网页并保存网页转 PDF 或下载原文件
  3. 通读内容、起中文文件名
  4. 上传 → 等待提取 → 双路合成
  5. 校验写回、汇报文件编号与来源链接

准备

确认能访问您的资料库

智能体核对访问权限，并告知当前使用的是哪个账号的资料

分岔

理解您想做什么？

根据您的说法，自动选择其中一条处理路径

默认原则：查、问、找、总结 → 一律先查资料库，不会悄悄去网上搜。
只有您明确说「外网 / 联网 / PubMed」等，才会走外网检索。

查资料库（最常见）

查一下、有没有、帮我总结、对比……（未要求外网时）

  1. 在资料库语义搜索按「意思」找相关段落，不是只搜文件名
  2. 补读关联资料若资料之间有主题链接，会一并展开阅读
  3. 整理证据、核对原文只依据库内真实内容，不用 AI 记忆瞎编
  4. 带出处回复您回答中注明文件名、页码或段落位置，方便您核对
资料库没找到？
会如实告诉您「库内未找到」，并询问是否要去外网搜索——不会擅自联网。

外网 / 文献检索

您明确说：外网、联网、PubMed、PMID、最新论文……

  1. （可选）先查一遍资料库若您说「库里查完再去外网」，会先查库
  2. 在外网或 PubMed 搜索找到公开网页、论文、报告等来源
  3. 整理成清单表格标题、来源、链接、摘要要点一目了然
  4. （可选）您确认后入库若要把外网资料存进库，再走「入库整理」流程

文件入库 / 整理

上传、入库、打标签、整理、维护知识库……

  1. 确认存放位置选哪个资料库、哪个文件夹；智能匹配或请您确认
  2. 上传或接收文件PDF、Office、图片、文本等
  3. 等待系统提取正文自动 OCR、解析表格与段落（复杂文件需稍等）
  4. 双路合成笔记专员文案处理流程（系统自动提取正文）与专业审核修订流程（AI 通读原文并整理结构）并行，合并为带「## 总结」的结构化资料笔记
  5. 打标签、写回资料库校验通过后，才向您汇报「入库完成」
已有资料要整理？
若笔记末尾已有「## 总结」定稿标记 → 跳过重写，只补标签或移动位置。
否则重新走双路合成，更新笔记。

链接入库

给一个网页或 PDF 链接，存成库内资料

  1. 打开链接、保存为文件网页会转成 PDF 保存；直链则直接下载
  2. 通读内容、起中文文件名按内容命名，不用网址尾巴当文件名
  3. 上传 + 双路合成笔记与「文件入库」相同：专员文案处理 + 专业审核修订 + 合并
  4. 校验后汇报结果告知文件编号、存放位置、来源链接、标签

待处理清单

看看还有哪些文件还没整理、没标签

  1. 拉取待处理列表已上传但尚无笔记、无标签的文件
  2. 逐篇等待提取完成PDF / Office 等需等系统解析完毕
  3. 写笔记、打标签、归档按您的优先级一篇篇处理
  4. 每步向您简短汇报让您知道进度，不必干等

Wiki 体检 / 主题页

断链检查、互链整理、补建概念主题页

  1. Wiki 体检扫描断链、孤立页、缺失主题标识等问题
  2. 向您说明发现列出问题清单，等您确认再修改
  3. （可选）修复链接 / 建主题页多篇资料共同引用某主题时，自动补建概念页
  4. 记录维护日志方便日后追溯做了什么改动
  • 查、问、找、总结 → 默认先查您的资料库，带文件名与原文出处回复
  • 明确说外网 / PubMed / 联网 → 走外网检索；库内与外网结果会分开标注
  • 资料库没找到 → 如实告知，询问是否扩到外网；不会悄悄联网或凭 AI 记忆作答
  • 上传 / 整理 / 入库 → 选位置 → 提取 → 双路合成 → 打标签 → 校验完成
  • 给链接 → 先保存网页 → 再按入库流程处理
  • 每完成一步 → 智能体会向您简短汇报进度，不必全程盲等
