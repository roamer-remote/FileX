# 钉 — 使用者介绍 PPT 写作纲要

> **用途**：面向**日常使用者**（研发、资料员、业务骨干等）的演示文稿写作提纲。  
> **侧重点**：钉**提供什么功能**、**您能得到什么好处**；少讲采购与架构，多讲「怎么用、解决什么痛」。  
> **建议篇幅**：12–15 页，约 10–15 分钟。  
> **风格建议**：亮色、清晰图示；每页「功能 → 好处」成对出现；可用前后对比（网盘 / 聊天上传 vs 钉）。

---

## 使用说明（给写稿人）

- 每页结构：**一句话价值** → **功能清单** → **对您的好处** → （可选）**一句话怎么用**。  
- **不要**把钉说成豆包/元宝替代品；强调：**浏览器管库 + 智能体办事**，二者配合。  
- 演示时可配：上传一个 PDF、展示资料笔记、语义搜一条、智能体带出处回答（录屏或截图）。

## 第 1 页 · 封面

**标题建议**：钉 — 您的个人资料库，让 AI 智能体「有据可查」

**副标题**：存得进 · 搜得到 · 引得出 · 越用越厚

**开场一句话（口播）**  
钉帮您把各类资料收进**自己的资料库**，并让支持技能包的 **AI 智能体**按规范查库、入库、**带文件名与原文摘录**作答——减少「AI 瞎编」和「资料散落找不到」。

**本页不讲**：理论渊源、公司采购理由。

| 您关心的 | 钉提供 | 您的好处 |
|----------|--------|----------|
| 资料放哪 | 个人资料库 + 二级文件夹 | 不再散在下载目录、邮件附件里 |

| 省事吗 | 智能体 + 钉技能包：入库、打标、网上文献一条龙 | 重复劳动交给 Agent，您只管提需求 |
| 活起来吗 | 笔记、标签、索引持续更新 | 库越用越整齐，不是一次性导入就烂尾 |

## 第 3 页 · 怎么用钉（两个入口）

**功能说明**

1. **Web 界面（浏览器）** — 上传、预览、文件夹整理、打标签、语义检索、资料目录、标签关系图。  
2. **AI 智能体 + 钉技能包** — 在 OpenClaw、Hermes、Claude Code、Codex、Cursor 等环境中安装 `/ding` 技能；**须**在宿主配置 `FILEX_ORIGIN` 与 `fb_` API Key（Hermes：`~/.hermes/.env`），用自然语言驱动：入库、检索、外网文献发现（Web 搜索 + PubMed）与整理等。

**对您的好处**

- 日常整理、自己查资料 → **打开网页即可**，不必会编程。  
- 批量、重复、跨多步的任务 → **交给智能体**，一条指令跑完流程。

**须知晓（一句话）**  
豆包、元宝等**聊天工具不能装钉技能包**；管库、带出处查资料请用 **Skill 智能体 + 钉**。

## 第 4 页 · 功能一：个人资料库与文件夹

**提供什么**

- 每人**独立**个人资料库，资料按用户隔离。  
- **二级文件夹**归档（如「文献 / 2025」「内规 / SOP」）。  
- 文件上传、预览、下载；支持常见办公与科研格式。

**您的好处**

| 痛点 | 钉之后 |
|------|--------|
| 文件堆在桌面、网盘链接满天飞 | 统一入口，按文件夹像整理书柜 |
| 怕和别人资料混在一起 | 个人库隔离，只看自己的 |
| 只记得文件名不记得内容 | 为下一页的「能搜内容」打基础 |

**怎么用（口播示例）**  
「拖进库 → 选文件夹 → 需要时在侧栏看预览。」

---

## 第 5 页 · 功能二：多格式自动提取笔记

**提供什么**

入库后自动提取正文，生成资料 **Markdown 笔记**（无需您手工 OCR/复制）：

| 类型 | 说明 |
|------|------|
| Office 新旧版 | Word / Excel / PowerPoint（.doc–.pptx） |
| PDF 可编排 | 电子版、可选中文字，直接抽正文 |
| PDF 图片版 | 扫描件、拍照 PDF，自动 OCR |
| 图片 | JPEG、PNG 等常见格式 |

**您的好处**

- **少一道工序**：不必先转 Word 再上传。  
- **检索更准**：系统优先按笔记做语义索引，比只存 PDF 更好搜。  
- **可人工润色**：笔记可编辑，智能体也可后续补写。

**对比一句**  
网盘只存文件；钉是 **存文件 + 读懂文件**。

---

## 第 6 页 · 功能三：语义检索（带原文片段）

**提供什么**

- 在**自己的库**里按自然语言 **语义检索**。  
- 返回最相关的 **原文片段** 及 **文件名**（钉侧重检索，不在钉里替您 Chat 出最终长文）。  
- **标签 + 语义并集**：查「重要资料」时，既命中打了该 **标签** 的文件，也命中 **向量语义** 相关、但未打该标签的文件（智能体检索默认用 `tag_combine: union`）。

**您的好处**

| 痛点 | 钉之后 |
|------|--------|
| 只记得「去年那份报告里写过类似观点」 | 用一句话描述意思即可搜到段落 |
| 怕 AI 编造内部数据 | 先拿到库内真实片段，再让智能体组织语言 |
| 关键词搜不到同义表述 | 语义检索覆盖「换种说法」的内容 |
| 只靠标签会漏同义文档 | 标签命中与向量命中 **合并** 返回 |

**口播示例**  
「在检索框输入：『XX 靶点临床前数据』→ 点开结果看原文摘录。」

---

## 第 7 页 · 功能四：标签、目录与知识网络

**提供什么**

- **标签**：给文件打标，支持筛选、合并（智能体可协助打标）。  
- **资料目录索引**：鸟瞰全库文件列表（AUTO 区随库更新）。  
- **标签关系图**：看哪些主题常一起出现，点选可 **AND 筛选** 文件列表。  
- **笔记内锚点**：从标签跳到资料笔记具体段落。

**您的好处**

- 从「一堆文件」变成 **看得见的主题结构**。  
- 发现「常一起出现的标签」= 发现知识团块与空白。  
- 写综述、做培训时快速圈定相关文献集合。

**视觉建议**：标签关系图截图 + 箭头示意「点边 → 筛文件」。

---

## 第 8 页 · 功能五：与 AI 智能体协作（钉技能包）

**提供什么**

- **钉技能包**（`/ding`）：教智能体何时查库、如何入库、如何 **必须带出处**。  
- 典型能力（经智能体执行）：  
  - **查库**（filex-kb-search）：标签 + 向量并集检索，带文件与摘录。  
  - **维护入库**（filex-maintain）：上传、打标、补笔记、重提取。  
  - **文献检索**（filex-research）：优先用环境内 Web 搜索发现公开资料；生物医学主题可用 PubMed；再整理入库。  
  - **待处理清单**：查看尚未打标、尚无笔记的文件。

**您的好处**

| 您说的一句话 | 智能体帮您 |
|--------------|------------|
| 「把这篇 PDF 入库并打上『临床』标签」 | 走规范 API，不丢步骤 |
| 「库里关于 XX 的已有结论？」 | 先检索钉，再组织回答，并引用文件名 |
| 「找近五年 XX 相关文献并入库」 | 外网/Web 或 PubMed 检索 → 下载 → 笔记 → 打标 → 可搜 |

**强调**  
您是 **指挥者**；钉是 **资料与规则的底座**。

---

## 第 9 页 · 功能六：网上资料一条龙入库

**提供什么**

通过智能体 + 钉技能包，可从网上获取公开资料并自动走完：

**查找/下载 → 入库 → 提取笔记 → 打标签 → 建立检索索引**

典型入口：Web 全网检索、PubMed 生物医学检索、公开 PDF/页面链接下载入库等（以部署环境与合规为准）。

**您的好处**

- **从「浏览器收藏夹」到「库里可搜」** 一次跑通。  
- 减少：下载 → 改文件名 → 上传 → 再打开 Chat 问一遍 的重复劳动。  
- 新人可复用同一套库，避免每人重复下载同一篇论文。

**场景举例（口播）**  
「告诉智能体主题 → 第二天在钉里按关键词能搜到昨晚入库的文献。」

---

## 第 10 页 · 功能七：分享与预览

**提供什么**

- **单文件分享链接**：可选密码、有效期、下载次数（由文件所有者创建）。  
- **在线预览**：PDF、Office、图片等（视格式支持情况）。  
- **API 密钥**（若您使用外部脚本/智能体）：个人密钥管理，停用即失效。

**您的好处**

- 外发资料可控，不必把整个库开放。  
- 同事点开链接即可查看，减少「发微信大文件失败」。  
- 智能体用您的密钥访问**您权限内**的库。

## 第 11 页 · 三个日常场景（故事线）

用 **Before → After** 讲好处，每场景 3 行即可。

### 场景 A · 科研 / 文献

- **以前**：外网或 PubMed 下 PDF → 本地文件夹 → 写综述时记不清哪篇说过什么。  
- **现在**：智能体按主题入库 → 钉内语义检索 → 回答带 **篇名 + 摘录**。  
- **好处**：少重复阅读，引用可核对。

### 场景 B · 内规 / SOP / 培训

- **以前**：制度 Word 版多，全文搜索靠记忆或文件名。  
- **现在**：入库自动笔记 → 按条款意思检索 → 培训材料引用具体段落。  
- **好处**：合规问答有据可查。

### 场景 C · 个人资料沉淀

- **以前**：资料越下越多，「待整理」文件夹永远满。  
- **现在**：待 AI 处理清单可见缺口 → 智能体批量打标补笔记 → 标签图看结构。  
- **好处**：库 **越用越整齐**，不是越用越乱。

## 第 12 页 · 索引与整理状态（心里有数）

**提供什么**

- 上传后可查看 **提取状态**（排队/提取中/完成/失败），失败可 **重新提取**。  
- **向量索引状态**：笔记就绪后可语义检索；支持手动 **重新索引**。  
- **待 AI 处理**：尚未打标或尚无笔记的文件列表（供您或智能体扫尾）。

**您的好处**

- 不用猜「这篇能不能搜了」——状态列告诉您。  
- 大文件提取失败可重试，不会悄悄失败。  
- 清单驱动整理，像「收件箱清零」一样有成就感。

## 第 13 页 · 快速上手（使用者 checklist）

**第一步 · 网页（5 分钟）**

1. 登录钉 → 进入个人资料库。  
2. 上传 1–2 个典型文件（如一篇 PDF、一份 Word）。  
3. 等待提取完成 → 打开资料笔记看一眼。  
4. 试一次语义检索 → 确认能命中段落。

**第二步 · 智能体（需 IT 或按文档自助一次）**

1. 在 OpenClaw / Claude Code / Cursor 等环境 **安装钉技能包**。  
2. 配置个人 **API 密钥**。  
3. 试一句：「列出我库里待处理的文件」或「检索 XX 主题」。

**第三步 · 养成习惯**

- 新资料 **先入钉再引用**；  
- 写材料前 **先让智能体查库带出处**；  
- 每周看一次 **待处理清单** 或标签图。

## 第 14 页 · 常见问题（使用者版）

| 问题 | 简短回答 |
|------|----------|
| 钉是聊天软件吗？ | 不是。钉是资料库与检索；聊天请用豆包/元宝，查库请用智能体+钉。 |
| 我能用豆包上传的文档代替钉吗？ | 不能替代。聊天上传偏临时问答；钉支持长期库、全流程入库与带出处检索。 |
| 钉会替我写综述吗？ | 钉提供 **证据片段**；成文由您或智能体中的大模型完成。 |
| 别人能看到我的文件吗？ | 默认 **个人库隔离**；仅分享链接或管理员策略可另议。 |
| 哪些格式会自动提取？ | Office 新旧版、可编排/图片版 PDF、常见图片等（见第 5 页）。 |
| 没有智能体能用吗？ | **能**用网页上传、检索、打标；**批量与网上入库**建议配智能体。 |
