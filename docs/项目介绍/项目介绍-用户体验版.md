# agentic 智能体驱动的核心能力
-  目标分解 (Task Decomposition)
    将复杂大目标拆解为可执行的子步骤 (Chain of Thought)。
- 工具调用 (Tool Use)
   自主使用网络搜索、API、代码解释器或企业内部系统。
- 记忆机制 (Memory)
   具备短期任务上下文记忆，结合 RAG 技术调用长期资料库与历史经验。
- 反思与学习 (Reflection)
  在执行中自我评估决策，遇到障碍时主动寻找替代方案。
