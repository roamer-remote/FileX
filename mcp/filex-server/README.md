# FileX MCP Server (optional)

Thin stdio MCP that calls FileX HTTP API.

```bash
export FILEX_ORIGIN=https://your-filex.example
export FILEX_API_KEY=fb_...
node index.js
```

Requires `@modelcontextprotocol/sdk` installed locally. Primary integration remains HTTP + `skill/ding/references/filex-agent-api.md`.
